## 在浏览器里：手机、平板或电脑

手机和电脑上用的是同一个网页，只是布局不同。手机上，对话列表收在左上角菜单按钮后面；在宽窗口里，它是一个侧栏，上面有「搜索对话」，对话按「今天」「昨天」「前 7 天」「更早」分组；`⌘\` 收起或展开侧栏。

- **打开**：网页一打开就显示你的 Mac 上次列出的模型，可以马上输入、选模型、发送；连接还没建好时发出的消息，连上后立即发出。模型旁边的小圆点在你的 Mac 回应之前会一直闪。
- **选模型**：模型选择在输入框里，分成「订阅（不另花钱）」「API Key」「你的 Mac 上」几组，每个模型前的小圆点表示它现在能不能用：绿色能用，灰色是连不上你的 Mac，橙色是要先处理一下，原因写在名字下面（这个订阅在你的 Mac 上没有登录，或用量到了上限、几点恢复）。选中橙色的模型时，输入框上方会提示怎么处理。
- **发图片**：点图片按钮拍照或选图，也可以直接粘贴；电脑上还可以把图片拖进窗口。每条消息最多 4 张。照片先缩小（长边 1600 像素）再发，原图不离开这台设备。Claude 和 Codex 都能看图；看不了图的模型会直接说明。
- **语音输入**：点输入框里的麦克风开始说话，按钮变成跳动的声波，说的字边听边出现在输入框里，接在已经打的字后面；再点一下、按 Esc、开始打字或停顿就结束。文字只填进输入框，不会自动发出。识别由浏览器完成：Chrome、Edge 把声音交给 Google，Safari 交给 Apple。不支持语音识别的浏览器（比如 Firefox）不显示麦克风。第一次用时浏览器会问能不能用麦克风。
- **停止**：回答过程中点「停止」（或按 Esc），只停这一次，下一条照常。
- **对话记录**：存在这个浏览器里，加密保存。用订阅模型（Claude、ChatGPT）时，你的 Mac 也会留一份，方便接着聊；一天没用就删掉。长对话里只有最近两条带图的消息会重新附上图片，免得请求越来越大。
- **「你的 Mac」菜单**：对话列表最下面的「你的 Mac」显示你的 Mac 在不在线。点开的菜单里有这台设备的名字、「语言」（「跟随你的 Mac」、中文、English）、「键盘快捷键」、对话存在哪里，以及「移除这台设备」。网页默认用你的 Mac 的语言（控制台或菜单栏里选的那个），也可以在这里给这台设备单独选。
- **开了几个标签页**：同一时间只有一个标签页保存对话。你回到哪个标签页，它就自己接过来，带上另一个标签页保存的内容。
- **断网**：设备没网时马上提示，刚输入的内容留在输入框里；联网后自动重新连上。
- **你的 Mac 关机或睡眠**：提示“连不上你的 Mac”。Mac 醒来后自动恢复，不用重新配对。
- **移除这台设备**：「你的 Mac」菜单里的「移除这台设备」会删掉这个浏览器里的配对和对话，并在你的 Mac 上同时移除它。Mac 当时连不上的话，会提示你之后在 Mac 的「设备」里也移除它。

电脑上的键盘快捷键（Windows 和 Linux 上用 Ctrl 代替 ⌘）：

| 按键 | 作用 |
|---|---|
| `⌘⇧O` | 新对话 |
| `⌘K` | 搜索对话 |
| `⌘\` | 收起或展开侧栏 |
| `Esc` | 停止回答 |
| `⌘⇧;` | 复制最后一条回答 |
| `/` | 跳到输入框 |
| `Enter` / `⇧Enter` | 发送 / 换行 |
| `⌘/` | 键盘快捷键 |

## 在终端里

在用 `install.sh --device` 装过、配对好的电脑或服务器上：

| 命令 | 做什么 |
|---|---|
| `omnillm connect chat [--model ID]` | 多轮对话。`/image 文件` 附图片，Ctrl-C 停止当前回答，Ctrl-D 退出 |
| `omnillm connect ask [--model ID] [--image 文件] "问题"` | 问一句就退出 |
| `omnillm connect models` | 列出这台设备能用的模型 |
| `omnillm connect run` | 在 `127.0.0.1:8766` 提供兼容 OpenAI / Anthropic 的本机接口，给这台机器上的程序用 |
| `omnillm connect pair` | 粘贴新的配对文字（换主机或重新配对） |
| `omnillm connect forget` | 移除这台设备（主机上也一起移除） |

订阅模型只有在真正的终端里手动输入时才能用。通过管道、cron、脚本调用，或者通过本机接口调用，都算后台程序，只能用 API Key 和本地模型。原因见[安全说明](security.md#尽量不被封号)。

## 管理设备和额度

在主机上打开控制台：点 Mac 菜单栏里的 OmniLLM 图标 →「打开控制台」，或运行 `~/.local/bin/omnillm open`（加 `--add` 直接打开添加设备的二维码）。

**菜单栏图标**（macOS）：装好后随登录自动出现，一直留在菜单栏里。看一眼就知道手机现在能不能连上（实心：能；虚线轨道、空心：连不上）。菜单第一行用文字说同一件事（比如“在线 · 手机和其他设备可以连上”）；下面的「设备」「模型来源」显示各有几个，点了打开控制台的对应页；然后是「添加设备…」「打开控制台…」、版本号和「检查更新…」，最后是「语言 · Language」，和控制台里的语言按钮是同一个设置。OmniLLM 没在运行时，菜单里有「启动 OmniLLM」。图标不见了的话，运行 `omnillm tray`。用了菜单栏整理工具（如 Ice、Bartender）的，新图标可能被收进隐藏区，拖出来即可。

| 页 | 能做什么 |
|---|---|
| 设备 | 「添加设备」（见[快速上手](quickstart.md#第-3-步加手机或平板)）。每台设备有「开启」开关：关掉就马上暂停，配对和设置都保留。「模型」一栏在设备能用全部模型时写「全部 4 个」，只能用一部分时写「部分 2 / 4」；鼠标停在这一栏或设备名字上，会出一张小卡片，列出能用的模型，或者添加时间、最近在线和今天用量。「编辑」改名字、每天额度（可以「不设上限」）和能用的模型：打开「全部模型」时，以后接入的新模型也自动可用；单独关掉一个模型，「全部模型」就关掉，其余照旧开着。「移除」立即生效 |
| 模型 | 接入 API Key、本地模型。在「模型来源」里，每个来源有「开启」开关：关掉后设备和应用暂时用不了它的模型，登录和 Key 都保留，再打开马上能用；「移除」才会删掉 Key。看每个模型的对话发往哪里（「只在这台 Mac 上」或「云端」），给模型改名或不在设备上显示，设置哪些模型「只能手动对话」（脚本和应用调用不了；订阅模型始终如此）。有应用或只给程序用的设备在用某个模型时，打开「只能手动对话」前会先列出它们再问你 |
| 应用 | 给主机上的脚本或程序发令牌（见[快速上手](quickstart.md#第-5-步可选让程序也能用)）；同样有「开启」开关、「模型」一栏和「编辑」。应用只能用 API Key 和本地模型 |
| 用量 | 每台设备、每个应用今天、昨天或最近 7 天用了几次、花了多少，也可以按模型看（按提供方公布的价格估算），已移除的合并成一行，最后是合计 |

页面顶部是今天的花费和**整台主机每天总额度**（默认 20 美元），点「修改」可以改，也可以不设上限。

命令行里也能做同样的事，见 `omnillm help`：

```bash
omnillm hub devices                 # 设备列表
omnillm hub revoke <名字或 ID>      # 移除一台设备
omnillm hub device set <名字或 ID> --paused true   # 暂停一台设备
omnillm hub provider off <来源>     # 关闭一个模型来源（on 打开）
omnillm hub models                  # 已接入的模型
omnillm hub usage                   # 用量
```

**额度**：每台设备默认每天 5 美元（估算），可以改，也可以「不设上限」——那时只受整台主机每天总额度限制；总额度也可以不设上限。订阅模型不按钱算（订阅已经付过），按次数限：每台设备每小时 60 次、每天 300 次；整个主机每分钟 12 次，一次只跑一个。

## 让主机一直能用

设备只能在主机开着、联网的时候用。

- **Mac 合上盖子或睡眠时，所有设备都用不了**，醒来后自动恢复。想随时能用，可以在「系统设置 → 电池（或能源）」里打开「接通电源时防止自动进入睡眠」，或者用一台常开的 Mac mini、Linux 服务器做主机。
- 主机重启、更新后，后台服务会自己起来，设备自动重新连上，不用重新配对。
- 主机换了网络（比如带着笔记本出门）没关系，设备会跟着自动重新连上。

## 提示和处理办法

| 你看到 | 原因 | 怎么办 |
|---|---|---|
| 连不上你的 Mac：它可能睡眠了或者没联网 | 主机睡眠、关机或断网 | 唤醒主机，会自动恢复 |
| 这台设备没有联网 | 手机自己没网 | 联网后自动恢复，输入的内容还在 |
| 你的 Mac 上的 Claude Code / Codex 没有登录或登录已过期 | 订阅登录过期 | 在主机终端运行 `claude`（或 `codex login`）重新登录 |
| 要用……，你的 Mac 上需要先安装 Claude Code / Codex 并登录 | 主机上没装，或被卸载了 | 在主机上运行 `omnillm login claude`（或 `chatgpt`），或用控制台里的卡片 |
| 订阅按一个人聊天的节奏使用，两次请求之间要隔开一点 | 一分钟内发得太快 | 等提示的时间；20 秒内能轮到的会自动等，不会报错 |
| 这台设备用订阅模型太频繁了 | 超过了每小时 60 次或每天 300 次 | 稍后再试，或换一个用 API Key 的模型 |
| ……的订阅用量到了上限 | Claude / ChatGPT 自己的用量上限 | 等它恢复（提示里有大约多久） |
| 这个模型只能手动对话 | 脚本或程序调用了订阅模型 | 换 API Key 或本地模型 |
| 这个模型的来源在你的 Mac 上关掉了 | 「模型」里把它的来源关掉了 | 在控制台里把它打开 |
| 这台设备已在你的 Mac 上暂停 | 这台设备的「开启」开关关着 | 在控制台「设备」里打开 |
| 你的 Mac 上这个版本的……关不掉工具 | 官方程序更新后，安全检查没通过 | 更新 OmniLLM；在那之前这个订阅暂时不用 |
| 这台设备今天的额度用完了 | 到了这台设备的每天额度 | 明天恢复，或在主机控制台调高 |
| ……的 Key（末 4 位 ……）不可用 | Key 失效或余额不足 | 在控制台换一个 Key |
| 图片不能用 | 格式不对或太大 | PNG、JPEG、GIF、WebP，每张 2 MB 以内，每条最多 4 张 |
| 这个模型看不了图片 | 选的模型不支持图片 | 换 Claude 或 Codex，或者只发文字 |
| 这台设备已从你的 Mac 上移除 | 在主机上被移除了 | 需要的话在主机上重新添加 |
| 这个二维码或配对文字已过期或已用过 | 二维码超过 5 分钟，或已经用过 | 在主机上重新点「添加设备」 |
| 配对文字不完整或被改动了 | 复制时少了或改了字符 | 在主机上重新完整复制一次 |
| 这不是 OmniLLM 的配对文字 | 复制错了东西 | 从主机控制台的「添加设备」里复制 |
| 远程连接暂时不可用 | 公共连接服务在维护或网络有问题 | 会自动重连；一直不行的话，看[项目主页](https://github.com/wensuper/OmniLLM)有没有公告 |

还是不行的话，主机上的日志在：

- macOS：`~/Library/Application Support/OmniLLM/hub/hub.log`
- Linux：`~/.config/OmniLLM/hub/hub.log`

日志里没有对话内容和 Key，提 Issue 时可以附上最后几十行（发之前自己再看一眼）。

## 更新和卸载

**更新不用管**：

- **主机**：开机后几分钟、之后每 6 小时看一次有没有新版本；有的话，等 10 分钟没人用的时候自己装上，重启只要几秒，手机和其他设备会自己重新连上。新版本启动不起来时，自动退回原来的版本，以后也不再自动装这一版。
- **网页**（手机、平板、电脑）：打开时自己换成新版，没发出的文字会保留。
- **Linux 服务器（只当设备用的）**：没有后台服务，不会自己更新；有新版本时 `omnillm connect` 会提一句。

**0.2.0-alpha.22 或更早的版本**还没有自动更新和 `omnillm update`：再运行一次安装命令（设置都保留），之后就不用管了。

**想马上更新**，在主机或服务器上运行（主机会重启几秒，手机上正在出的回答会中断）：

```bash
omnillm update            # 有新版本就更新；已是最新就直接说
omnillm update --check    # 只看看有没有新版本
```

Mac 上也可以点菜单栏的 OmniLLM 图标 →「检查更新…」，有新版本时那一行会变成「有新版本 … · 点击更新」。`omnillm status` 会告诉你有没有新版本、是不是在等空闲时自动更新。

**关掉自动更新**：`omnillm update --auto off`（重新打开：`--auto on`）。之后有新版本只提示，不自己装。

更新就是用最新的发布重新安装一遍（现在还都是预发布版）：同一个安装脚本，同样先核对校验和（装了 cosign 还核对签名），设置、Key 和已配对的设备都保留。再运行一次安装命令也是一样的效果；在只当设备用的服务器上运行，它会按设备更新，不会把服务器变成主机。

**卸载主机**：

```bash
~/.local/bin/omnillm uninstall          # 停止并删除后台服务，保留数据和 Key
~/.local/bin/omnillm uninstall --purge  # 同时删除数据和保存的 Key
rm -f ~/.local/bin/omnillm
```

`--purge` 只删除本机保存的 Key。Key 在提供商那里仍然有效，不再用了请到提供商后台作废。订阅登录属于 Claude Code / Codex，卸载 OmniLLM 不会动它。

**卸载设备**：服务器上运行 `omnillm connect forget`，再删掉 `~/.local/bin/omnillm`；浏览器里用「你的 Mac」菜单里的「移除这台设备」。主机当时连不上的话，之后在主机的「设备」里也移除它。

## 常见问题

**要花钱吗？**
OmniLLM 免费开源（Apache-2.0），公共连接服务也免费。用到的模型按你原有的方式付费：订阅照常、API 按量、本地模型免费。

**会不会被封号？**
OmniLLM 尽量让用法看起来就是你本人在自己的电脑上用：只从主机发请求，订阅只给人手动对话，限速，遇到限流就停。但能不能用、会不会受限，最终由提供商决定，请遵守它们的条款。详见[安全说明](security.md#尽量不被封号)。

**可以分享给家人或同事用吗？**
不行，这是有意的设计。一个主机只服务一个主人和他自己的设备：把订阅分给别人用，本来就违反大多数提供商的条款，也是最容易被封号的用法。

**公共连接服务是谁在运行？能看到我的对话吗？**
由项目作者运行在 `relay.ixxzh.com`。它只转发加密数据，看不到对话内容；能看到 IP、连接时间、流量大小这类元数据。不放心的话可以[自己部署](self-host.md)，一个程序加一条命令。

**为什么手机上不用装 App？**
网页客户端里运行的是和命令行客户端同一份加密代码（WebAssembly），在浏览器里就能完成端到端加密。代价是第一次打开网页时要信任托管方，详见[安全说明](security.md#手机上的网页客户端)。

**主机可以是 Linux 服务器吗？**
可以。安装方法一样，没有浏览器时用 `omnillm hub provider add` 在终端里接 API Key，配对二维码和确认都在终端里完成（`omnillm hub pair`）。用订阅的话，在服务器上装好并登录 Claude Code 或 Codex 就行。

**Windows 呢？**
暂不支持做主机，Windows 电脑可以用浏览器打开网页客户端当设备用。

**能在自己的程序里用吗？**
可以。在设备上运行 `omnillm connect run`，得到一个兼容 OpenAI 的本机接口（只能用 API Key 和本地模型）。Go 程序还可以把 OmniLLM 当库嵌入，见[设计文档](../design.md#24-库优先一套代码两种用法)。
